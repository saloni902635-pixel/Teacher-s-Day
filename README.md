# Happy Teachers' Day — Sakshi Ma'am 🌸

A 4-step animated Streamlit surprise page for Sakshi Ma'am, Class Coordinator,
3rd Year B.Tech Biotechnology.

## Run locally

```bash
pip install -r requirements.txt
streamlit run app.py
```

Then open the local URL shown by Streamlit.

## Deploy on Streamlit Community Cloud

1. Create a GitHub repository.
2. Upload:
   - `app.py`
   - `requirements.txt`
   - `assets/sakshi_mam.jpeg`
3. In Streamlit Community Cloud, select the repository and `app.py` as the main file.
4. Deploy.

The photo is stored locally in `assets`, so the app does not depend on an external image URL.


### Streamlit Cloud image check

The photo must be committed to GitHub at exactly:

`assets/sakshi_mam.jpeg`

GitHub paths are case-sensitive. Commit/push the complete `assets` folder.
